serdes

SerDes 是 Serializer / Deserializer 的缩写，中文通常翻译为：
串行器 / 解串器（也叫串并转换器）

https://www.mr-wu.cn/wp-content/uploads/2021/03/SerDes-%E7%9F%A5%E8%AF%86%E8%AF%A6%E8%A7%A3.pdf

  • 系统同步的问题

a)、时钟到达两个芯片的传播延时不相等(clock skew)

b)、并行数据各个bit的传播延时不相等(data skew)

c)、时钟的传播延时和数据的传播延时不一致(skew between data and clock)

  • 相比源同步接口，SerDes的主要特点包括:

a) SerDes在数据线中时钟内嵌,不需要传送时钟信号。

b) SerDes通过加重/均衡技术可以实现高速长距离传输，如背板。

c) SerDes 使用了较少的芯片引脚

差分信号技术

在选择高速差分信号技术时有很多选择。不同的技术通常共享某些特性，但在性能、功耗和目标应用程序方面差异很大

LVDS(Low-Voltage Differential Signaling)：低电压差分信号
CML（Current Mode Logic）：电流模式逻辑
Low Voltage Positive Emitter Coupled Logic 低电压正射极耦合逻辑。

LVDS驱动器和接收器

驱动器中含有一个3.5mA的电流源。因为接收器的输入阻抗很高，故整个电流实际上全部流过100Ω的终接电阻，于是在接收器输入端产生了350mV的电压。接收器的阈值可以保证为100mV或更低，可在0V-2.4V的宽共模范围内维持这样的灵敏度水平，提供出色的噪声裕量。

CML（Current Mode Logic）

所有差分技术共有的优点：
首先，电流源始终导通，但电流被引导流向不同的方向，以驱动逻辑0/1。这种始终保持的特性可以消除开关噪声带来的尖峰和大电流晶体管不断导通-关断造成的电磁干扰（EMI）。
其次，构成差分对的两条导线的间距很短，可以保证较高的抗噪性能。一条导线所吸收的串扰或EMI也会同时出现在另一条临近导线上。
另外，由于两条临近的导线传输的电流相同，方向相反，故而产生的EMI很低。

LVDS是最常用的高速接口，具有低功耗和宽共模的双重优点。
LVPECL通常使用额外的功率，但支持非常高的数据速率和出色的抖动。
CML设备提供与LVPECL相似的性能，并且具有简单且通常集成的终端的优势
