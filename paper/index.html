名称 全称 本质 是否掉电保存 AI芯片里的作用
Flash Flash Memory 非易失存储 ✅ 保存 保存模型文件、固件
ROM Read-Only Memory 只读存储 ✅ 保存 存固定参数、启动代码
SRAM Static RAM 高速读写存储 ❌ 不保存 缓存权重、激活值、中间结果
BRAM Block RAM FPGA里的SRAM ❌ 不保存 FPGA上存权重和缓存
MAC Multiply-Accumulate 乘加计算单元 不适用 执行神经网络计算
NoC Network-on-Chip 片上互连网络 不适用 在SRAM、MAC、控制器之间传输数据
OTA Over-The-Air 在线升级机制 不适用 更新模型、固件或软件
Hard-coded Constant 硬编码常数 参数直接变成电路逻辑 不涉及存储 综合器把常数优化进门电路，而不是存进ROM/SRAM

方案 参数放哪里 速度 面积 功耗 能否更新
Hard-coded 根本不存，综合进逻辑 不一定更快（有时略快） ⭐ 最小 ⭐ 最低 ❌ 不行
ROM ROM 快 小 低 ❌ 不行
SRAM SRAM 很快 中 中 ✅ 可以
HBM HBM 比SRAM慢，但带宽极高 很大 高 ✅ 可以
DDR DDR 更慢 最大 高 ✅ 可以
